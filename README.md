# SmartLearn Agent

## Project Overview

SmartLearn Agent is an AI-powered learning assistant that helps students read PDF documents, summarize content, and answer questions based on uploaded materials. It is designed as a beginner-friendly project to explore AI-driven document understanding.

## Planned Features

- 📄 **PDF Text Extraction** — Parse and extract text content from PDF files
- 📝 **PDF Summarization** — Generate concise summaries of document contents
- ❓ **Question Answering** — Answer user questions based on uploaded documents
- 🔖 **Paragraph and Page Citations** — Provide accurate citations referencing specific paragraphs and pages
- 💬 **Multi-turn Q&A** — Support follow-up questions in a conversational manner
- 🔍 **RAG Support** — Retrieval-Augmented Generation for more accurate and context-aware responses
